# 걷기 애니메이션 수정용 통합 프롬프트

아래 코드 블록 전체를 복사해서 애니메이션 작업자에게 전달한다.

```text
MurimRPG 플레이어의 걷기 애니메이션 한 가지를 다듬어 주세요. 이번에는 게임 런타임, 서버, 걷기 속도 설정, 다른 행동의 모션을 수정하지 않습니다. Blockbench 자유 모델의 편집 가능한 걷기 클립이 산출물입니다. 화면을 원격 조작하지 말고 파일을 읽고 별도 결과 파일을 만들어 주세요.

[입력과 현재 상태]
- 프로젝트 저장소: MurimRPG-restored-20261017/minecraft_murim
- 공개 중립 스킨 리그: assets-source/blockbench/player-animation-template/player_current_weighted_armature.bbmodel
- 공개 걷기 초안: assets-source/blockbench/player-animation-template/player_current_weighted_walk_editable.bbmodel
- 현재 스킨이 포함된 로컬 전용 걷기 초안: 상위 작업 폴더의 플레이어_Blockbench_수정용/현재_플레이어_걷기_편집용_v4.bbmodel
- 리그 제작 도구: assets-source/blockbench/player-animation-template/build_weighted_armature_player.py
- 걷기 초안 생성 도구: assets-source/blockbench/player-animation-template/add_weighted_walk.py
- 이 리그는 Minecraft 플레이어의 32픽셀 높이와 64×64 와이드 스킨 UV를 유지합니다. 머리는 한 덩이의 기본 표면이며, 몸통과 머리는 연속 메시입니다. 각 팔과 다리는 다른 팔다리와 분리되어 있고, 각 팔다리 안에서는 관절 부근의 표면이 이어집니다. 허리와 몸통 사이에 lowerBack 뼈가 있습니다. 어깨 윗면 정점은 각 UpperArm을 따라갑니다.
- 기존 v2/v3/v4 원본, 사용자의 다른 미저장 모션, player_animation_wide.bbmodel은 덮어쓰거나 삭제하지 마세요. 로컬 스킨·텍스처를 공개 저장소에 올리지 마세요.

[이번 목표]
1. 걷기만 1.2초 안팎의 부드러운 제자리 반복으로 완성해 주세요. 달리기처럼 급하게 회전하거나 2~3배속으로 보이지 않아야 합니다. 정확한 길이는 프레임 간 연속성과 체감 속도를 확인해 1.0~1.3초 사이에서 정하되 변경 이유를 기록하세요.
2. 좌우 다리는 반대 위상으로 교대하고, 뒤에서 앞으로 나오는 다리에는 무릎 굽힘을 자연스럽게 넣으세요. 발이 바닥에 닿는 구간은 상대적으로 안정적으로 유지하고, 앞으로 회수하는 구간이 접지 구간보다 약간 빠르게 느껴지게 하세요. 발 미끄러짐이나 튀는 무릎을 피하세요.
3. 팔은 다리와 반대 위상으로 작게 흔들되, 검·검집 등 손에 든 물건을 다룰 수 있도록 과장된 각도는 피하세요. 이번 클립에 공격 동작이나 손 아이템 자체의 이동은 넣지 마세요.
4. lowerBack과 chest에는 사람 걷기처럼 미세한 무게 이동과 상체의 반동만 넣으세요. 앞뒤로 심하게 숙이거나 몸이 뻣뻣한 막대처럼 보이지 않도록 하세요. 머리는 시선이 크게 출렁이지 않게 보정하고, 몸통 비틀기는 작게 유지하세요.
5. root의 위치 키와 전체 캐릭터의 전진 이동은 넣지 마세요. 게임이 실제 이동을 담당합니다. 모델의 크기, 메쉬·UV·스킨·뼈 계층·관절 위치·가중치는 바꾸지 마세요. 다른 애니메이션을 추가하거나 수정하지 마세요.
6. 관절 연결부의 찢어짐, 어깨 윗면의 고정, 팔·다리 사이에 면이 늘어나는 문제, 머리의 겹친 덩어리가 새로 생기면 그 프레임을 기록하고 최소한으로 고치세요. 원본 모델 구조 변경이 필요하다면 먼저 별도 제안으로 설명하세요.

[초안의 숫자와 편집 기준]
- 초안은 60 FPS 표기, 1.2초 길이, 0.1초 간격 12구간과 종료 키 1개로 구성됩니다. 시작 키와 종료 키는 같은 자세입니다.
- 다리 앞뒤 회전은 최대 약 23도, 팔은 약 15도입니다. 무릎은 약 0~16도, 팔꿈치는 약 3~7도입니다. lowerBack, chest, neck의 회전은 각각 몇 도 이하의 작은 보정입니다. 이 수치가 결과 품질을 보장하지 않으므로 실제 프레임의 균형과 연결 상태를 보고 조절하세요.
- 수정할 주요 뼈: rightLeg, leftLeg, rightKnee, leftKnee, rightArm, leftArm, rightElbow, leftElbow, lowerBack, chest, neck. 필요하면 발목·발에 작은 회전을 추가할 수 있지만 위치 이동이나 히트박스 변경은 금지합니다.
- 균일한 사인파처럼 기계적으로 보이면 접지/회수 구간의 타이밍과 무릎·팔의 위상을 조절하세요. 프레임 수만 무작정 늘리거나 모든 관절에 큰 진폭을 주지 마세요.

[검증과 제출]
- 입력과 출력 .bbmodel을 각각 파싱하고, 메쉬·텍스처·뼈 계층·UV·vertex_weights가 같으며 애니메이션 부분만 변한 것을 확인하세요. 시작/종료 키의 각도와 반복 경계의 속도도 비교하세요. root 위치 키가 없는지 확인하세요.
- 앞·옆·뒤 시점에서 시작, 양쪽 접지, 중간 통과, 반대쪽 접지, 종료 자세를 확인할 수 있는 프레임 표와 관찰 결과를 제시하세요. 직접 시각 확인이 불가능하면 그 사실을 분명히 쓰고 구조 검증만 통과했다고 보고하세요.
- 로컬 현재 스킨 결과는 플레이어_Blockbench_수정용 아래 새 이름으로 저장하고, 공개 중립 스킨 결과만 GitHub용으로 제공하세요. 원본은 보존하세요.
- 산출물: (a) 수정 가능한 별도 .bbmodel, (b) 변경한 뼈·시간·각도 표, (c) 검증 결과와 미확인 항목, (d) 사용자가 Blockbench에서 어떤 클립과 뼈를 열어 조절하면 되는지 5줄 이내 안내.
- 실제 Minecraft 적용이나 인게임 자연스러움은 별도 F5 확인 전까지 완료했다고 주장하지 마세요.
```
