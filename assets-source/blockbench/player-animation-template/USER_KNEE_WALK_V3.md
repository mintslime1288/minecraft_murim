## 확인 범위

공개·로컬 결과의 무릎 키가 같고, 사용자 0초 자세와 1.2초 끝
자세가 일치하며, 애니메이션 외 모든 모델 데이터가 각각 입력과
같음을 파일 파싱으로 확인했다. Blockbench에서 로컬 새 파일을 열어
0초와 0.95초의 자세를 보았다. 현재 보이는 각도에서 무릎 연결면의
뚜렷한 찢어짐은 보이지 않았지만, 발은 지면에서 떠 보일 수 있다.
움직이는 동안의 발 접지와 게임 이동 중 자연스러움은 아직
판정하지 않았고 인게임에는 적용하지 않았다.

Blockbench **애니메이션** 탭에서 위 클립을 선택하고
`rightKnee`·`leftKnee`의 X 회전을 조절한다. 0초 키는 사용자
기준점이므로 그 자세를 유지하려면 0초와 1.2초의 값을 함께
바꾼다. 0.30초와 0.95초에서 회수 중 무릎 굽힘을 비교한다.
