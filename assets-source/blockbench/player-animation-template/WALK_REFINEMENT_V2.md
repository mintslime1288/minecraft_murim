# 걷기 애니메이션 다듬기 v2 (2026-10-25)

## 산출물

- 공개 중립 스킨: `player_current_weighted_walk_refined.bbmodel`
- 현재 스킨 로컬 전용: 상위 작업 폴더의
  `플레이어_Blockbench_수정용/현재_플레이어_걷기_다듬기_v2.bbmodel`

- Blockbench에서 **애니메이션 → 걷기_접지회수_다듬기_1.2초**를 고른다.

기존 v1·v4와 `player_animation_wide.bbmodel`은 보존했다. 게임 코드,
설정, 서버, 다른 행동 모션은 변경하지 않았다.

## 변경 근거

v1은 접지와 회수가 각각 반 주기였다. v2는 한 다리 기준 접지 구간을
0.70초, 발을 앞으로 회수하는 구간을 0.50초로 분리했다. 좌우 접촉은
0.60초 어긋난다. 접지와 회수 경계에서 회전 속도가 0에 접근하도록
각 구간에 완만한 이징을 썼다. 리그의 크기와 뼈 길이를 근사한 발목
높이 계산에서 접촉 자세의 바닥 위 거리는 v1 약 1.33픽셀에서 v2
약 0.88픽셀로 줄었다. 이 값은 메시 변형이나 실제 게임 이동을 포함하지
않으므로 **접지를 시각적으로 확인했다는 뜻은 아니다.**

다리 앞뒤 회전은 ±23도에서 ±20도로, 팔은 ±15도에서 ±12도로 줄였다.
무릎은 접지 중 약 4~6도, 회수 중 최대 22도로 만들었다. 팔꿈치는
약 4~7도다. `lowerBack`·`chest`·`neck`에는 작은 회전만 남겼다.
`root`와 다른 뼈의 위치 이동 키는 없다. 회전 키는 11개 뼈에
0.05초 간격으로 각 25개, 총 275개다. 반복 첫 키와 끝 키가 같다.

## 검증과 사용자 확인

파일 파싱으로 메시·텍스처·UV·뼈 계층·`vertex_weights`를 포함한
애니메이션 외 모든 프로젝트 필드가 입력과 같은지 확인한다. 시작/끝
키가 같고, 루트 및 다른 뼈에 위치 키가 없고, 한 샘플의 최대 회전
변화량이 약 5.92도임을 검사한다. 공개본과 로컬본의 애니메이션은 같다.
화면은 사용자 요청에 따라 조작하지 않았으므로 앞·옆·뒤 시점의
실제 메시 찢어짐, 접지, 발 미끄러짐은 **미확인**이다. 인게임 적용도
하지 않았다.

Blockbench에서 위 클립을 열어 재생하고 앞·옆·뒤에서 0.00, 0.30,
0.60, 0.95, 1.20초를 살펴본다. 발이 뜨면 접촉 시점의 다리 X와
무릎 X를, 상체가 어색하면 `lowerBack`·`chest`를 먼저 조절한다.
사용자 수정은 로컬 파일에 저장하고 공개용 중립 스킨과 혼동하지 않는다.
