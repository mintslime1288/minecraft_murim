# 걷기 어깨 끝점 교차 v7

사용자의 정정: 몸통을 좌우로 옮기거나 팔 자체를 좌우로 돌리는 것이
아니다. 위에서 볼 때 **몸통 중심에 연결된 좌우 어깨의 바깥 끝점**이
걸음에 따라 앞뒤로 서로 자리를 바꿔야 한다.

v4의 현재 스킨·중립 스킨 파일을 각각 입력으로 사용했다. v5의 몸통 X
위치 키와 v6의 팔 Z 회전은 포함하지 않는다. 원본 v4, v5, v6는 보존했다.

| 시점 | 오른쪽 어깨 연결 Y | 왼쪽 어깨 연결 Y | 오른·왼 끝점의 국소 앞뒤 깊이 근사 |
| --- | ---: | ---: | --- |
| 0초 | −9.9616° | −10° | +0.87 / −0.87픽셀 |
| 0.3초 | 0° | 0° | 0 / 0 |
| 0.6초 | +9.9616° | +10° | −0.87 / +0.87픽셀 |
| 0.9초 | 0° | 0° | 0 / 0 |
| 1.2초 | −9.9616° | −10° | 첫 자세와 동일 |

연결 관절은 몸통 중앙에 있고, 양팔 시작점은 각각 X=+5와 X=−5다.
따라서 연결 관절의 Y 각도가 바뀌면 바깥 끝점의 국소 Z 위치가 반대로
이동한다. 기존 0초 쇄골 각도를 유지하고 1.2초 주기의 25개 프레임에서
양쪽 끝점을 서로 반대 방향으로 교대시켰다. 팔 자체의 `rightArm`·
`leftArm` 회전, 기존 앞뒤 팔 흔들기, 접지와 무릎, 몸통 위치, 메시·UV·
스킨·가중치·본 계층은 수정하지 않았다. 게임 코드·서버·이동 속도·
다른 행동 모션도 변경하지 않았다.

JSON 구조 검사에서 모델과 대상 외 애니메이션 키가 v4와 같고,
0초와 1.2초의 자세가 같다. 위 표의 끝점 깊이는 어깨 연결 관절과
팔 시작점의 국소 좌표로 계산한 값이며, 실제 메시 변형의 안전성을
증명하지 않는다. Blockbench에서 **위에서 본 시점**으로 0초와
0.6초의 양쪽 어깨 끝점 위치를 비교하고, 0.3초와 0.9초에서
중앙을 통과하는지 확인한다. 앞·뒤 시점에서는 어깨 윗면이 몸통과
벌어지거나 겹치지 않는지 본다. 인게임 보행과 손 아이템은 미확인이다.
