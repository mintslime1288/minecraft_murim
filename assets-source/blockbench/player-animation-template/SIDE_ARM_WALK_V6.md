# 걷기 팔 좌우 움직임 v6

사용자의 정정: 좌우로 움직여야 하는 것은 몸통이 아니라 **양팔**이다.
따라서 v5의 몸통 이동을 가져오지 않고, 사용자 0초 자세와 접지 보정이
들어 있는 v4에서 새 편집본을 만들었다. v4·v5는 보존했다.

| 시점 | `rightArm` Z | `leftArm` Z | 화면에서 확인할 동작 |
| --- | ---: | ---: | --- |
| 0초 | 0° | 0° | 사용자의 시작 자세 유지 |
| 0.3초 | +5° | +5° | 오른팔은 바깥, 왼팔은 안쪽 |
| 0.6초 | 0° | 0° | 팔 좌우 중앙 통과 |
| 0.9초 | −5° | −5° | 오른팔은 안쪽, 왼팔은 바깥 |
| 1.2초 | 0° | 0° | 시작 자세로 반복 |

모델에서 오른팔 기준점은 X=+5, 왼팔 기준점은 X=−5다. 같은 Z 회전
부호를 두 팔에 적용하면 한쪽은 바깥으로, 반대쪽은 몸 안쪽으로
움직인다. 0.05초 간격의 기존 팔 회전 키 25개에서 Z만 바꿨다.
팔의 앞뒤 X 회전, 발 접지용 `waist` Y·발목, 사용자가 저장한
등허리·가슴·어깨·골반 회전, 모델·스킨·UV·가중치·본 계층은 보존했다.
`waist` X는 전 구간 0이고 `lowerBack` 위치 키는 없다. 게임 코드,
이동 속도, 서버, 다른 모션은 변경하지 않았다.

구조 검사에서 공개 중립 스킨과 현재 스킨 로컬본 모두 각 v4 입력과
애니메이션 외 필드가 일치했고, 양팔 Z 이외의 모든 키가 같았다.
공개·로컬 팔 키도 서로 같다. Blockbench에서 0.3초와 0.9초를
앞·뒤에서 비교하고, 팔이 몸통을 관통하거나 손의 아이템이 너무
옆으로 흔들리면 `rightArm`·`leftArm` Z 진폭을 함께 줄인다.
실제 인게임 보행과 아이템 쥐기는 아직 검증하지 않았다.
