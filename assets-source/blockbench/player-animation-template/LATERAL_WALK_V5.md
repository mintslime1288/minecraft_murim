# 걷기 좌우 체중 이동 v5

사용자 지적: 이전 v4의 골반 상하 이동은 보이지만 좌우 움직임이 부족하다.
이번 단계에서는 좌우 이동 채널만 추가했다. 기준은 v4의 공개 중립 스킨
편집본과 현재 스킨 로컬 편집본이다. 둘 다 덮어쓰지 않았다.

| 시점 | 지지 방향 | `waist` 위치 X | `lowerBack` 위치 X | 상체 총 이동 X |
| --- | --- | ---: | ---: | ---: |
| 0초 | 오른발 체중 수용 | 0 | 0 | 0 |
| 0.3초 | 오른발 지지 | +0.12 | +0.48 | +0.60 |
| 0.6초 | 왼발 체중 수용 | 0 | 0 | 0 |
| 0.9초 | 왼발 지지 | −0.12 | −0.48 | −0.60 |
| 1.2초 | 반복 경계 | 0 | 0 | 0 |

모델 좌표에서 오른다리 기준점은 X=+2, 왼다리는 X=−2다. 1.2초
주기로 부드럽게 양쪽을 오가는 0.05초 간격의 25개 키를 만들었다.
골반 이동을 ±0.12픽셀로 제한해 지지 발의 횡방향 미끄러짐을 줄이고,
등허리 이동 ±0.48픽셀로 상체의 체중 이동을 보이게 했다. `waist`의
기존 Y 접지 보정, 다른 모든 회전 키, 0초 사용자 자세, 모델 메시·UV·
웨이트·스킨·본 계층은 보존했다. `root` 이동과 게임 전진 이동은 없다.

검사: 공개·로컬 출력 모두 각 입력과 애니메이션 외 구조가 동일하고,
변경 대상 이외의 모든 채널이 같다. 두 출력의 좌우 위치 키는 같으며
0초와 1.2초 값이 일치한다. 수치상 지지 방향은 확인했지만 실제
Blockbench 재생에서 관절 면의 늘어남과 보행의 자연스러움, 인게임
발 미끄러짐은 사용자가 눈으로 판단해야 한다. 확인 시에는 0.3초와
0.9초의 상체 중심 위치를 앞면에서 비교하고, 옆·뒤 시점에서
등허리 면을 살핀다. `lowerBack` X를 먼저 조절하면 상체 좌우 폭을,
`waist` X를 조절하면 발의 횡이동 폭을 조절할 수 있다.
