# 통나무 수련대 — Meshy 원본 시안 1

이 폴더에는 Meshy Text-to-3D로 만든 원본 GLB와 미리보기가 로컬에 보관된다.

- 원본 크기: 약 114MB
- 리메시 파생 GLB: 약 12.4MB, 목표 8,000 폴리곤
- 상태: 전용 클라이언트 렌더러 연결 전
- 이유: 원본 크기는 게임에 너무 크다. 경량 파생 파일은 준비됐지만, 실루엣이 목표인 팔각 통나무보다 직육면체에 가깝다.

이 원본을 현재 리소스팩 또는 게임 JAR에 포함하지 않는다. `model-optimized.glb`는 전용 GLB 렌더러 프로토타입 후보이며, 최종 적용 전에는 라이선스 검토와 실제 게임 성능·실루엣 검수가 필요하다.
