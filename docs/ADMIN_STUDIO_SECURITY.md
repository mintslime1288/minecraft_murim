# MurimRPG Admin Studio 설계 및 보안

Admin Studio는 일반 플레이어에게 배포하지 않는다. 운영 명령은 서버의 권한 검사와 감사 로그를 거쳐야 한다.

## 안전한 초기 범위

- 서버 상태, 온라인 플레이어, TPS, 최근 오류를 읽기 전용으로 표시
- 화폐·훈련 아이템·EXP 지급은 서버의 기존 관리자 명령어 API만 호출
- 모든 작업에 관리자 식별자, 시각, 대상, 성공/실패를 기록

## 금지

- RCON 비밀번호, Microsoft 계정 정보, 운영 비밀을 코드·Git·manifest에 기록하지 않는다.
- RCON을 공인 인터넷에 그대로 열지 않는다.
- 임의 콘솔 명령 실행, 무차별 엔티티 삭제, 비밀값 자동 생성은 기본 기능으로 넣지 않는다.

RCON 또는 전용 HTTPS 관리자 API 선택은 서버 공개 환경·방화벽·인증 방식이 확정된 뒤 결정한다.
