# 세력·조직·계급

## 정파 — 무림맹 (`MURIM_ALLIANCE`)

- 오대세가: 남궁세가 `NAMGUNG_FAMILY`, 하북팽가 `HEBEI_PENG_FAMILY`, 제갈세가 `ZHUGE_FAMILY`, 모용세가 `MURONG_FAMILY`, 사천당가 `SICHUAN_TANG_FAMILY`
- 구파일방: 화산파 `HUASHAN_SECT`, 종남파 `ZHONGNAN_SECT`, 무당파 `WUDANG_SECT`, 소림사 `SHAOLIN_TEMPLE`, 개방 `BEGGARS_GANG`

## 사파 — 사도련 (`SADO_ALLIANCE`)

- 흑도: 녹림 `GREEN_FOREST`, 장강수로채 `YANGTZE_RIVER_STRONGHOLDS`, 살막 `ASSASSIN_HALL`, 하오문 `HAO_GATE`
- 사교: 마교 `DEMON_CULT`, 혈교 `BLOOD_CULT`

플레이어의 직접 소속은 연합이 아닌 산하 조직 하나다. 현재 인게임에는 구파일방만 보이고 화산파만 가입 가능하다.

## 확정 계급

- 문파형: `SECT_MASTER`, `ELDER`, `FIRST_GENERATION_DISCIPLE`, `SECOND_GENERATION_DISCIPLE`, `THIRD_GENERATION_DISCIPLE`
- 세가형: `FAMILY_HEAD`, `YOUNG_FAMILY_HEAD`, `ELDER`, `RISING_JUNIOR`
- 마교형: `HEAVENLY_DEMON`, `YOUNG_CULT_LEADER`, `COUNCIL_OF_ELDERS`

마교 장로회 아래, 혈교와 흑도의 계급은 미확정이므로 추가하거나 공유하지 않는다.
