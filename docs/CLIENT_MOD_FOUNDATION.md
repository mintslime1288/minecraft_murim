# 전용 클라이언트 기반

MurimRPG는 Fabric 서버 전용 모드에서 클라이언트·서버 공용 모드로 확장됐다. 현재 단계는 고밀도 모델을 넣기 전의 안전한 기반 작업이다.

## 현재 포함된 기능

- `MurimRpgClient` 클라이언트 진입점
- 서버가 보내는 `murimrpg:server_hello` 프로토콜 확인 패킷
- 클라이언트의 접속/해제 상태 관리
- 향후 GLB 모델, 파티클, 사운드, 사용자 UI가 사용할 공용 네트워크 경로

현재 프로토콜 버전은 `1`이다. 서버는 해당 패킷을 받을 수 있는 MurimRPG 클라이언트에만 패킷을 보내므로, 고밀도 렌더링을 아직 추가하지 않은 이 단계에서는 바닐라 클라이언트 접속을 강제로 차단하지 않는다.

## 다음 단계: 통나무 수련대 GLB 세로 기능

1. Meshy에서 생성한 상업 사용 권한이 확인된 `.glb` 원본과 텍스처를 프로젝트에 추가한다.
2. 모델의 라이선스, 원본 프롬프트, 폴리곤 수, 텍스처 해상도를 기록한다.
3. 서버가 수련대 위치·회전·피격 상태만 전송한다.
4. 클라이언트 전용 렌더러가 GLB를 로컬 모드 자산에서 읽고 화면에 그린다.
5. 이 단계부터는 서버 접속에 MurimRPG 클라이언트 모드를 요구하도록 전환한다.

GLB 파일을 네트워크에서 임의 다운로드하지 않는다. 검증된 모드 JAR 또는 모드팩 자산에 포함해 배포한다.
