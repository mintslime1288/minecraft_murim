# MurimRPG 게임 디자인

## MVP 범위

이번 MVP는 아래 콘텐츠만 대상으로 고정한다. 이 문서는 범위를 정의할 뿐, 현재 기반 구축 단계에서 실제 무공·사냥 시스템을 구현하지 않는다.

- 문파: **홍매검문** 1개
- 공용 경공: **유운보**, **비연답공**
- 문파 무공: **홍매연검**, **낙화반격**
- 대경지: **삼류**, **이류**, **일류**
  - 삼류: 입문, 하수, 중수, 평정
  - 이류: 초기, 중기, 후기, 원만
  - 일류: 초기, 중기, 후기, 절정
- 사냥터: **흑송산채** 1개
- 몬스터: 일반 2종, 정예 1종
- 보스: **흑송채주** 1종
- 승급은 확률형이 아니며, 실패 확률이나 파괴 확률을 두지 않는다.

## MVP 제외 범위

- PvP
- 파티
- 거래
- 제작
- 과금 시스템

제외된 기능은 별도의 범위 변경과 설계 검토 없이 구현하지 않는다.

## 현재 데이터 구현 범위

현재는 삼류·이류·일류의 12개 소경지를 누적 수련 EXP와 명시적 승급 조건으로 한 단계씩 진행할 수 있다. 승급은 실패 확률이 없으며 EXP와 조건이 충족되면 확정적으로 성공한다. 경지 도달 시 콘텐츠 ID가 프로필에 해금되지만, 해당 무공·경공·시각 효과의 실제 기능은 구현하지 않는다.

대경지 경계 조건은 다음과 같다.

- 삼류·평정 → 이류·초기: `training_trial`
- 이류·원만 → 일류·초기: `black_pine_chief`

`setprogress`, `resetprogress`, `addexp`, `setexp`, `requirement`, `testprogress` 관리자 명령은 개발·수동 검증 전용이며 실제 게임 진행 수단이 아니다.
