# MurimRPG 게임 디자인

## MVP 범위

이번 MVP는 아래 콘텐츠만 대상으로 고정한다. 이 문서는 범위를 정의할 뿐, 현재 기반 구축 단계에서 실제 무공·사냥 시스템을 구현하지 않는다.

- 문파: **홍매검문** 1개
- 공용 경공: **유운보**, **비연답공**
- 문파 무공: **홍매연검**, **낙화반격**
- 대경지: **삼류**, **이류**, **일류**
  - 삼류: 입문, 하수, 중수, 평정
  - 이류: 초기, 중기, 후기, 원만
  - 일류: 초기, 중기, 후기, 절정
- 사냥터: **흑송산채** 1개
- 몬스터: 일반 2종, 정예 1종
- 보스: **흑송채주** 1종
- 승급은 확률형이 아니며, 실패 확률이나 파괴 확률을 두지 않는다.

## MVP 제외 범위

- PvP
- 파티
- 거래
- 제작
- 과금 시스템

제외된 기능은 별도의 범위 변경과 설계 검토 없이 구현하지 않는다.

## 현재 데이터 구현 범위

현재는 플레이어의 경지·수련 EXP·완료 조건 ID·해금 콘텐츠 ID를 저장하고 관리자 테스트 명령으로 직접 변경할 수만 있다. 실제 승급 조건 판정, 승급 실행, 무공, 경공, 몬스터, 장비 시스템은 구현하지 않는다. `resetprogress`와 `setprogress`는 개발·수동 검증 전용이며 실제 게임 진행 수단이 아니다.
