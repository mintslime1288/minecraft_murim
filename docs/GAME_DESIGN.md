# MurimRPG 게임 디자인

세력·조직·계급의 정본은 `FACTIONS_AND_RANKS.md`와 YAML이다. 홍매검문 단일 문파 기획은 폐기되었다. 데이터에는 정파/사파, 무림맹/사도련, 16개 산하 조직을 분리해 보존하지만 현재 인게임 `/문파 목록`에는 무림맹 산하 구파일방 5개만 노출한다.

## 현재 플레이 가능한 화산파 흐름

1. 화산파 입문 시험과 육합공 수련을 완료해 삼대제자가 된다.
2. `/문파 승급`으로 이대제자 승급 시험을 시작한다.
3. 자기 시험용 일대제자 NPC 체력을 50% 이하로 낮추면 이대제자가 된다.
4. 다시 `/문파 승급`으로 일대제자 승급 시험을 시작한다.
5. 자기 시험용 산적 대장 `BANDIT_LEADER`를 처치하면 일대제자가 되고 자하신공을 습득한다.

50% 기준, 표시명, NPC 최대 체력, 몬스터 수치는 YAML에서 변경한다. 시험관은 50% 경계에서 죽지 않고 시험 성공과 함께 제거된다. 다른 플레이어 소유 시험관 공격은 거부하며 산적 대장은 소유자가 처치해야 한다.

실제 자동 배치, 재시도/실패 정책, 다른 네 문파의 콘텐츠, 일대제자 이후 계급은 현재 범위가 아니다.
