# 프로젝트 상태

## 구현됨

- Java 25, Paper API `26.2.build.112-stable`, Gradle Wrapper 기반 단일 플러그인
- SQLite 스키마 버전 1의 플레이어 프로필 저장과 비동기 캐시/종료 flush
- 문자열 대경지·소경지 ID를 사용하는 삼류~생사경 32단계 진행
- 누적 EXP, 일곱 경계 조건, 기존 12단계 해금 ID 저장
- `/murim status`, `profile`, `realm`, `cultivate` 및 관리자 테스트·진단 명령
- 설정 기반 최고 단계, 테스트 준비 EXP/조건, EXP 자동완성

## 미구현

실제 내공 소비·회복과 운기조식, 돌파 시험·퀘스트, 문파·세가, 무공·경공, 몬스터·보스, 장비, PvP, 파티·거래·제작·과금은 구현하지 않았다. 새 고급 경지 20단계의 해금 콘텐츠도 정의하지 않았다.

## 데이터 주의

컬럼 변경이 없어 마이그레이션은 추가하지 않았다. 기존 1~12단계 프로필은 그대로 호환된다. 기존 서버의 12단계 `realms.yml`은 자동 덮어쓰지 않으므로 백업·이름 변경 후 새 32단계 기본 파일을 생성해야 한다. 새 대경지 ID가 저장된 DB를 이전 JAR로 롤백하면 로드할 수 없으므로 배포 전 DB 백업이 필요하다.
