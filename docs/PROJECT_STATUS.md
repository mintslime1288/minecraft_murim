# 프로젝트 상태

## 구현됨

- Java 25/Paper 26.2, SQLite 스키마 v6, 기존 캐릭터·경지(삼류~생사경 32단계) 진행
- YAML 기반 2개 연합, 16개 조직, 문파형·세가형·마교형 계급과 시작 시 참조 검증
- 인게임 공개 조직은 구파일방 5개로 제한하며, 실제 입문 콘텐츠는 화산파만 제공
- 화산파 입문 수련과 육합공, 운기조식
- 삼대제자 → 이대제자: 소유자 전용 일대제자 시험관 체력을 `quests.yml`의 50%까지 감소
- 이대제자 → 일대제자: 소유자 전용 `BANDIT_LEADER` 처치 및 자하신공 습득
- 시험 엔티티의 콘텐츠 ID·소유자 UUID를 Paper PDC에 저장

## 영속성과 호환성

최신 DB 스키마는 v6이다. 기존 v2~v4 콘텐츠/여정 테이블과 v5~v6 캐릭터 컬럼을 그대로 사용하며 이번 작업은 신규 마이그레이션이나 초기화를 하지 않는다. `sect_id` 같은 과거 컬럼도 삭제하지 않는다. 경지·EXP·조건·해금과 캐릭터 데이터는 문파 상태 저장과 독립적으로 유지된다.

## 미구현

종남파·무당파·소림사·개방 입문, 실제 승급 NPC 배치/리스폰 정책, 일반 몬스터 스폰·AI, 기여도 획득, 탈퇴, 일대제자 이후 승급, 무공 피해·쿨다운은 아직 구현하지 않았다.
