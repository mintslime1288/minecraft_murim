# 전용 클라이언트 연출

MurimRPG의 전용 Fabric 클라이언트는 서버가 보낸 **연출 전용** 패킷만 재생한다. 피해, EXP, 경지, 아이템은 서버가 계속 결정하므로 클라이언트만으로 보상을 만들 수 없다.

클라이언트는 서버의 SQLite·YAML·명령어 초기화를 실행하지 않는다. 서버 접속 전 메뉴나 싱글플레이에서도 안전하게 모드만 초기화되며, 서버에서 받은 패킷이 있을 때만 연출을 재생한다.

## 현재 구현 연출

- `WOODEN_SWORD_SWING`: 목검으로 훈련 허수아비를 타격할 때 명확한 검 휘두르기 궤적과 타격음.
- `TRAINING_DUMMY_HIT`: 통나무 수련대의 타격 파편.
- `REALM_BREAKTHROUGH_SUCCESS`: `/강호 돌파` 성공 시 원형 기운 파동.
- `REALM_BREAKTHROUGH_FAIL`: 돌파 조건이 모자랄 때 약한 연기 파동.

각 값은 서버의 `config/murimrpg/effects.yml`에서 관리한다. 서버를 재시작해야 YAML 변경이 반영된다.

## 자연스러운 기본 애니메이션

걷기, 맨주먹 공격, 검 휘두르기는 Minecraft 26.2의 기본 플레이어 애니메이션이 재생된다. MurimRPG는 그 위에 서버 동기화된 궤적·충격 연출을 추가한다. 플레이어 뼈대를 새로 움직이는 애니메이션은 GLB 리깅/전용 렌더러를 위한 다음 단계이며, 기존 바닐라 플레이어 스킨과 충돌하지 않도록 아직 강제로 교체하지 않는다.

## 수동 확인

1. Fabric 프로필로 접속한다.
2. `/아이템관리 지급 GODyjy 목검 1`, `/아이템관리 지급 GODyjy 훈련허수아비 1`을 실행한다.
3. 허수아비를 설치하고 목검으로 공격한다.
4. 목검 주변의 짧은 궤적과 통나무 충격 파티클, EXP 메시지를 확인한다.
5. 돌파 가능 상태에서 `/강호 돌파`를 실행해 기운 파동을 확인한다.
